portable core is unchanged; development-only zero-inclusive selection
chooses alpha=0.10 and beta=1.25 at candidate_k=100. Use

## Verification and Reproduction

From the asset root, Python 3.10+ with NumPy can run:

```bash
python check_revision_implementation.py
cd implementation
PYTHONPATH=src python -m pytest tests
```

The parity check compares the public core with the research implementation
on synthetic empty, singleton, tied and mixed-scale candidate sets. It is
not a rerun of the dataset experiments. The portable API and explicit
revision config can rerank candidates produced by the normal repository
pipeline.

Research results can be inspected without raw data. Complete re-execution
requires separately obtained DOTA-v1.5/SODA-A data, matching encoder
checkpoints, and the cache layout recorded by each driver. Research drivers
are an execution record, not a one-command installer. Historical freeze
guards refer to the original private workspace and are not a fresh-run
protocol. Set up new local paths and a new audit record rather than
overwriting original results or treating a new run as the original freeze.

The public export replaces local path prefixes with generic placeholders
and removes private document-hash entries and internal planning prose.
Numerical experimental outcomes are unchanged. Historical script/file
hashes describe the original execution; `PUBLIC_EXPORT.json` identifies
changed or omitted files, and `SHA256SUMS.txt` validates this public export.
No claim is made that redacted execution scripts retain their original hashes.
Optional figure-layout helper code with unverified redistribution terms is
not included. Obtain third-party baseline code using `UPSTREAM_DEPENDENCIES.txt`.

For fixed-detector replay, follow `downstream_detection_20260917/reproduction.md`
inside the asset. Saved predictions permit CPU metric replay with separately
obtained SODA-A annotations; the private detector checkpoint is not provided.

## Evidence Boundaries

Results cover controlled, known-present categories and intra-image patch
reranking. They retain the large-window bias, weak independent auxiliary
component effects, projected-area reversals and detector false-positive
trade-off. The additional 1,067-image confirmation is distinct from reused
evaluation cohorts. No test outcome was used to reselect the revision weights.

Original submission results remain in v1.0.0 and `results/tables/`.
MIT applies to the authors' code/configurations and derived numeric results;
third-party datasets, pretrained models and baseline implementations retain
their original terms.
